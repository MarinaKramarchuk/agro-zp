# Технічне завдання — Агро-Зарплата

Опис призначення й функціоналу застосунку обліку шляхових листів і розрахунку
зарплати для агропідприємства. Документ описує проєкт у тому вигляді, в якому
він існує зараз (демо-версія для портфоліо, з вигаданими даними) — як орієнтир
для розробки, а не історичний бриф.

## Призначення

Замінити паперові шляхові листи й ручний розрахунок зарплати обліковця
агропідприємства на самостійний (self-hosted, без хмари) веб-інструмент:
внесення шляхових листів, розрахунок суми за тарифом чи погодинно, табель,
відомість ЗП, друк офіційних бланків.

## Стек

- **Backend**: Node.js (Express 5) + SQLite (`better-sqlite3`), валідація `zod`.
- **Frontend**: React + Vite + Tailwind CSS, `react-router-dom`.
- **Запуск для кінцевого користувача**: портативний Node у `runtime/`,
  запускачки `Відкрити облік.bat` / `Зупинити облік.bat` — без консолі
  розробника, бекенд сам роздає зібраний `frontend/dist`.

## Модель даних

- **Працівники** — ПІБ, посада, група (водій / тракторист / інше), особистий
  оклад за місяць (для погодинної оплати).
- **Техніка** — назва, держ. номер, категорія, марка (звʼязок із тарифами).
- **Марки техніки** — довідник марок (МТЗ, Джон Дір, ДАФ, КАМАЗ, Claas тощо).
- **Поля** — назва, площа, культура.
- **Види робіт** — каталог назв робіт із прапорцями: ремонтна робота,
  контроль площі, роль хіміка/помічника, транспортний тариф.
- **Тарифи** — одна ставка на комбінацію вид робіт × техніка × інвентар ×
  одиниця виміру; підтримує складені тарифи (напр. "72,5 грн/год + 5 грн/т")
  і тариф "від мінімалки" (сума вводиться вручну).
- **Міжміські рейси** — фіксована сума за маршрут або ставка грн/км за
  діапазоном відстані.
- **Шляхові листи** — основна сутність: працівник, техніка, поле (якщо
  потрібно), вид робіт, показники виробітку, розцінка й сума знімком
  (зміна тарифу заднім числом не перераховує минулі записи).

## Бізнес-логіка розрахунку суми

- `pay_mode: 'tariff'` — сума = ставка × обсяг (+ друга складова для
  складеного тарифу), з довідника тарифів, маршруту або введена вручну.
- `pay_mode: 'hourly'` — погодинно за особистим окладом працівника (або
  поточною мінімальною ЗП, якщо оклад не вказано); ставка = оклад / норма
  робочих годин місяця.
- **Доплата "хімік 50%"** — коли хіміка не було, водій-оприскувач бере на
  себе його роботу і отримує 50% від тарифу хіміка за оброблену площу.
- **Оплата за транспортним тарифом** — фактичний вид робіт і обсяг
  фіксуються як завжди, але сума рахується як години × ставка транспортного
  тарифу (підбирається за технікою, з фолбеком на типову ставку).
- **Замикання періоду** — після виплати місяць можна закрити: шляхові листи
  за цей місяць більше не можна створити/змінити/видалити, доки не відкрити
  назад.

## Розділи меню

| Розділ | Призначення |
|---|---|
| Огляд | дашборд-зведення за період |
| Дані з техніки | факти мотогодин/пального з телеметрії |
| Плани робіт | план на день, окремо від фактичних шляхових |
| Реєстрація роботи | форма внесення шляхового листа з розрахунком «на льоту» |
| Журнал робіт | список і фільтр усіх шляхових листів |
| Друк бланків | друк шляхового листа (форми №68/№2/№67-б) і розрахункового листа |
| Табель | сітка працівники × дні, кольори за годинами |
| Ремонт (години) | облік годин ремонту техніки окремо від виробітку |
| Відомість ЗП | зведений розрахунок зарплати, експорт у Excel |
| Контроль гектарів | факт площі з шляхових проти площі поля, по кожному виду робіт |
| Довідники | Працівники, Техніка, Поля, Види робіт, Тарифи, Міжміські рейси |

## Інтеграції з зовнішніми системами

- **OVERSEER** — імпорт Excel-вигрузки телематики техніки (мотогодини,
  пальне); немаплені машини потрапляють у сповіщення.
- **Hecterra** — імпорт виконаних агрооперацій (культивацій) з експорту;
  немаплені поля/види робіт/водії — теж у сповіщеннях.
- **BAS FOR AGRO** — вивантаження шляхових у формат для завантаження в
  бухгалтерську систему (орієнтовний формат).
- **Gektera** — зарезервовано під майбутню інтеграцію, ще не реалізовано.

## Демо-дані

Для демонстрації проєкт наповнюється вигаданими даними
(`backend/scripts/seed-demo-data.js`): фіктивні працівники, техніка, поля,
тарифи (реалістичні для с/г України, але не реальні розцінки жодного
підприємства), і кілька десятків демо-шляхових листів.
